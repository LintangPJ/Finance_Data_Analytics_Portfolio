# Day 14: Week 2 Mini Project, Excel Variance Model

## Overview
I built a dynamic variance analysis model in Excel to automate tracking actuals against the budget. 

## How it works
1. **Dynamic Retrieval:** I used nested INDEX and MATCH functions to pull specific line items based on what the user selects.
2. **Scenario Toggles:** The model includes a feature to instantly switch between Best, Base, and Worst-case assumptions without altering the raw data.
